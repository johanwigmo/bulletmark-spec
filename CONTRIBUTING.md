# Contributing to BulletMark

Thanks for your interest in BulletMark!

## About This Project

BulletMark is primarily a personal specification that I (@johanwigmo) use for my own note and task management workflow. I evolve it based on what I need in my daily use. That said, if you find it useful, that's fantastic! I'm happy to hear about it. 

## Philosophy

- **Personal-use first**: The spec evolves based on my own needs and use cases
- **Stability matters**: Breaking changes are rare and follow semantic versioning
- **Additions welcome**: Non-breaking additions that don't add complexity are great
- **Simplicity wins**: The spec stays minimal and focused

## How You Can Contribute

### Reporting Issues

Found something unclear or broken? Please open an issue: 
- Ambiguities in the specification
- Parsing edge cases that need clarification
- Typos or unclear documentation
- Examples that don't work as expected

### Suggesting Additions

Have an idea for a new feature? I'm open to suggestions, especially:
- **Non-breaking additions** that enhance existing functionality
- **Clarifications** that make parsing easier
- **Examples** from real-world usage
- **Test fixtures** for edge cases

**Note:** I may not accept additions that don't fit my workflow or that add significant complexity. This isn't personal - it's about keeping the spec focused on what I actually use. 

### Proposing Breaking Changes

Breaking changes are unlikely to be accepted unless:
- They fix a fundamental design flaw
- They're necessary for parser implementation
- The current behavior is genuinely problematic

If you need different behavior for your use case, consider:
- Creating your own fork or variant
- Adding it as an optional extension in your implementation
- Opening an issue to discuss if there's a non-breaking approach

## How to Submit

1. **Open an issue first** to discuss anything beyond typo fixes
1. For small fixes: just submit a PR
3. For additions: explain your use case and why it fits

## Questions? 

Open an issue. I'm happy to chat about BulletMark and help clarify things.
